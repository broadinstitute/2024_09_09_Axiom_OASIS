# Figure navigation copies

These JPEG files make the published figures visible from `paper.md` and easy for an agent to inspect.
They are navigation copies, not pixel-level reproduction targets.
The figure-specific acceptance rules in `../targets.tsv` govern reproduction.

Figures 1-4 were rendered from the four author-supplied vector PDFs in the submission bundle at an effective 180 pixels per inch and trimmed to visible content.
Those source PDFs use a tenfold page scale, so the renderer was set to 18 PDF pixels per inch.
The rendered images were visually checked against the camera-ready figures.

Figures S1-S4 were rendered at 150 pixels per inch from pages 2-5 of the committed `../sources/supplemental-figures.pdf` and trimmed to visible content.
Page 1 is the publisher cover sheet and is intentionally omitted.
